## Declan Jeffrey

Welcome to my personal GitHub account! Here lies all my personal coding projects.

I am currently focused on writing AI-Assisted web applications using different frameworks, languages, libraries, databases, and more!

**Projects Information**

🤖 <ins>AI-Final-Project :</ins>
 * This repo is from my Artificial Intelligence final from my senior year of University.
 * Within this repo lies a reinforcement learning agent developed in OSBot, that lives within the Old School RuneScape video game domain.
 * We utilized q-learning, to reward and punish the agent based on simple tasks like cutting down trees and getting experience/gold.
 * During the process, we had to overcome interesting problems like grid scoring, bot banning, and other players online.

🥅 <ins>WEB-API-.NET :</ins> 
 * Simple CRUD Web API created in the .NET core framework.
 * Got experience using C#, HTML, CSS, and Javascript.
 * Allows for the creation and modification of To-do items, as well as an additional creation of financial items.
 * For the most part I used a Microsoft tutorial to help me get started. Then I added my own spin onto it by practicing creating a financial helper section that allows the user to create a table full of financial items                that either add or subtract from their total expenses. 
 * I created Models for different items, a Database Context for each item, as well as a controller to handle HTTP requests.
 * I learned about what Data Transfer Objects (DTOs) are and how they assist in hiding private information from the users, but not from priviledged users.

🐍 <ins>DjangoPollingTutorial :</ins> 
 * Basic Django APP for framework and API practice.
 * The goal for this project was to learn more about Django and its framework setup. As well as included tooling, libraries, and useful shortcuts. Additionally, just get continuous practice coding, testing, using GitHub, and          debugging.
 * I learned the basics of the Django framework, creating views and models, creating database migrations, CSRF protection and more! Look into the project for more information.

 🥾 <ins>Spring-Boot-Project :</ins> 
 * Extremely basic Spring Boot project.
 * The main goal here was to just get exposure to the Spring Boot Framework, Apache Maven tooling, and Project Object Models.

 📁 <ins>Personal-Portfolio (In-Progress) :</ins> 
 * This was my attempt at setting up a personal portfolio website.
 * It was created within .NET in C# and JavaScript.
 * The main goal was to consolidate all my projects, resources, information, and documents that related to me and my experiences.
 * I never actually ended up hosting it or getting it finished up. I mainly focused on improving my LinkedIn and GitHub profiles.
 * I am actually currently working on improving this, and setting it up as a GitHub page. Allowing other people to view all my information in one place!

 🧩 <ins>Google-Chrome-Extension-HelloWorld :</ins>
 * Another basic tutorial, this time with the goal of learning how to create and package personal extensions in Google Chrome.
 * At my old Job, we often had to install and unpack custom Google Chrome extensions for things like cookie handling, and authentication.
 * I wanted to at least get a baseline understanding of how easy it is to do this yourself.
 * I intend to expand upon this project and create a more complex and useful extension for personal use.

 ✅ <ins>Task_Scheduling_React_Node :</ins> 
 * This is one of my first heavily AI assisted projects.
 * The goal here was to create a simple web application using React and Node.JS. Getting more experience working in the languages, styling out websites, and effectively using AI.
 * Additional tooling used here as well includes Postgres and Docker.
 * It is a simple task scheduling app with daily, weekly, and monthly views. Allowing users to create timed tasks, complete, delete, edit, and schedule events.
 * Look into the Readme for more information!
